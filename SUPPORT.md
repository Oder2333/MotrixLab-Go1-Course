# Support

- Use **Discussions** for usage questions and design discussion.
- Use an **Issue** only for a reproducible bug or a concrete feature request.
- Include the commit, operating system, Python version, uv version, selected
  backend/extra, and the smallest reproduction.
- Do not include secrets, private PyPI URLs, robot network addresses, or
  personally identifying data.

MotrixLab is maintained on a best-effort basis. Hardware support depends on
the robot vendor SDK, network setup, and a safe test environment.
